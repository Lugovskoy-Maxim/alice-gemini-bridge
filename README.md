# Алиса × Gemini

Локальный webhook-сервер для навыка Алисы в Яндекс Диалогах. Принимает запросы Яндекса и отвечает через Gemini API. Панель настройки и Google API-ключ остаются на сервере приложения.

## Быстрый запуск на macOS или Linux

Нужен Node.js 20 или новее.

```sh
node --version
npm start
```

Откройте [http://localhost:8787](http://localhost:8787), добавьте ключ Gemini API из Google AI Studio и сохраните настройки. Ключ хранится в `data/config.json`, файл создаётся с правами владельца (`0600`) и исключён из Git.

Локальная проверка диалога доступна в панели приложения. Для проверки из Яндекс Диалогов добавьте HTTPS адрес webhook с путём `/alice/`. Кнопка Cloudflare Quick Tunnel в приложении выдаёт временный адрес. Он действует, пока запущены приложение и туннель, и может измениться после перезапуска.

## Яндекс Диалоги

1. В настройках навыка выберите backend «Webhook URL».
2. Укажите публичный HTTPS адрес, заканчивающийся на `/alice/`.
3. Проверьте приветствие и обычный вопрос во вкладке «Тестирование».

Для постоянной работы на VPS используйте свой домен с HTTPS или публичный сертификат для статического IP. Пример настройки systemd и Nginx находится в [DEPLOYMENT.md](DEPLOYMENT.md). Сервер приложения слушает только `127.0.0.1`; через Nginx наружу нужно публиковать только webhook-путь `/alice/`.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `8787` | Порт локального HTTP-сервера |
| `APP_DATA_DIR` | `./data` | Каталог конфигурации с Gemini API-ключом |
| `CLOUDFLARED_PATH` | `cloudflared` из PATH | Путь к `cloudflared`, если нужен Quick Tunnel |

## Cloudflare Worker

Папка `cloudflare-worker/` содержит необязательный прокси. Для Worker задайте `UPSTREAM_ORIGIN` на текущий HTTPS адрес туннеля, без `/alice`, затем разверните его через Cloudflare Dashboard или Wrangler. Для собственного VPS Worker обычно не нужен: Яндекс может обращаться к HTTPS endpoint Nginx напрямую.

**Безопасность:** `/alice/` — публичный endpoint без пользовательской авторизации, как требует стандартный webhook-навыка. Ограничивайте частоту запросов на Nginx/Cloudflare и задайте лимит расходов Gemini в Google AI Studio. Панель настройки не проксируйте наружу.
